# PDF Extract and Chatbase Web App

## Features:
- Upload PDF.
- Extracts text using Python.
- Displays extracted text.
- Chat with Chatbase embedded.

## How to run:
1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000/

## Deployment:
Use Render.com for free hosting.
